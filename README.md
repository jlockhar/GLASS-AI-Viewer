# GLASS-AI Viewer
An application to view whole slide images and GLASS-AI classifications.

Select an input image used for GLASS-AI analysis and/or the GLASS-AI results (i.e, '*_classes.mat' or '*_overall_tumor_grades.mat') and press the `Load image(s)` button. 

You can zoom and pan within the viewer in the right panel. The opacity of the GLASS-AI result overlay can be adjusted using the slider at the bottom left.

*Note: If you use a .svs or .qptiff file, the slide label and macro images will be presented when the viewer is zoomed out. Zooming in will switch to the proper images. Unfortunately, there's no easy way to avoid this behavior.*
